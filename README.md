# HelpDesk Queue

A small React app for managing laboratory assistance requests. Students can join the queue, choose a priority, and track requests as they are resolved.

## Features

- Add and remove assistance requests
- High-priority requests are sorted first
- Mark requests as resolved
- Filter by all, waiting, or resolved requests
- Saves queue data in the browser
- Light and dark mode

## Getting started

Make sure Node.js is installed, then run:

```bash
npm install
npm run dev
```

Open the local address shown in the terminal. To create a production build:

```bash
npm run build
```
